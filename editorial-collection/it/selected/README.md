# Testi selezionati — Italiano

Qui vengono conservate le versioni italiane pulite dei testi scelti per la raccolta principale.

Formato del nome file:

`01-titolo-del-testo.md`

Ogni file deve indicare:

- titolo e sottotitolo;
- stato editoriale;
- data della versione;
- tema e possibile collocazione nel libro;
- testo completo;
- note per la revisione finale.
