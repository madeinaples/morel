# Testi da valutare — Italiano

Qui vengono conservati i testi italiani validi ma non ancora confermati per la raccolta principale.

Un testo passa in `selected` soltanto quando:

- aggiunge qualcosa di nuovo al percorso del libro;
- non ripete un tema già espresso meglio altrove;
- funziona anche senza il contesto del sito;
- regge una lettura consecutiva insieme agli altri capitoli.
